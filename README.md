## About

Full-stack e-commerce web application developed in 2016. This project features a complete online store with product catalog management, shopping cart functionality, and payment processing integration.

## Features

- Product catalog with hierarchical categories
- Shopping cart with cookie and database persistence
- Stripe payment gateway integration
- Admin panel for product, category, and brand management
- User authentication with permission-based access control
- Responsive design with Bootstrap framework

## Project Structure

```
├── admin/           # Administration panel
├── core/            # Database initialization
├── includes/        # Frontend components
├── helpers/         # Utility functions
├── css/             # Stylesheets
├── js/              # JavaScript libraries
└── fonts/           # Web fonts
```

## Requirements

- PHP 5.6+
- MySQL 5.x
- Apache Web Server
- Composer
